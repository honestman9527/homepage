## 主要流程与会话

- 桌面初访打开 About / Terminal，Terminal 在前但不自动聚焦输入；手机初访只打开 About。主操作“看看我在折腾什么”完整可见并打开项目；次操作打开终端且明确聚焦输入。
- 桌面入口、Dock、搜索和终端 `open` 打开同一应用始终单实例；重复点击活动 Dock 应用不关闭、不最小化。
- 终端输入草稿、提交记录并滚动阅读，随后最小化、手机切换、整理桌面、跨桌面和单窗口模式，内容与阅读位置保留；关闭再打开（含立即重开）得到新会话。
- 关闭或最小化活动应用后转到最近的其他 open 应用；没有候选时回桌面，焦点落在可见入口。最小化应用不被自动恢复，关闭的应用不被自动重开；关闭非活动窗口不改变原活动应用。
- 桌面整理恢复 About / Terminal 普通窗口构图，其他运行应用最小化；手机整理把 About 置前。现有应用会话与偏好不丢失，关闭的默认应用创建新会话，非默认关闭应用保持关闭。
- 项目卡片“了解项目”进入同窗详情；返回恢复原列表滚动与卡片操作焦点。隐藏、跨模式与整理后详情仍在；关闭重开回列表顶部。列表项移除时返回仍落到有效目标。
- 在线地址与源码链接各自独立，新标签打开；本站不自链，构想无演示入口，项目状态与“本站”身份分开。空项目、未配置博客、图片失败均有可用降级，不生成假链接。

## 窗口、键盘与辅助技术

- 普通窗口可以自由按 Tab 离开；前后窗口中的文本选择、滚动与链接正常，点击内容可置前。桌面可见的非活动窗口仍可操作；隐藏后台与最小化内容退出键盘和辅助技术交互范围。
- 只从标题栏空白拖动；控制按钮不触发拖动或提前置前错误窗口。右下角手柄可缩放；指针完成、取消与捕获释放均停止操作，边界处标题栏和关闭按钮可达。
- 绿色按钮与双击标题栏空白使用同一最大化 / 还原行为，不进入浏览器全屏；最大化先恢复再拖动。窗口缩小与旋转后控制区仍可达，普通几何在跨模式后合理恢复。单窗口不显示最小化 / 最大化控制，不可自由拖缩。
- Ctrl / ⌘ K 从不同入口切换同一搜索面板；中文、英文、ID、别名和关键词匹配正确，空查询列出五应用，无结果有空态。方向键、Enter、Escape、遮罩关闭均正常。
- 搜索打开后背景暂停交互，Tab / Shift+Tab 限制在面板内；取消回到可见触发入口，打开应用后移交目标窗口。Dock 与快捷键均可搜索，外部点击与 Escape 正确收起；顶部状态栏与 Dock 共用搜索，Escape 不关闭应用。
- 仅用键盘完成项目探索、返回、博客入口、设置和终端使用；焦点清晰，窗口关闭后不落在已移除内容。读屏逐项核对中文按钮名、窗口名称、当前应用、运行状态、表单标签与新标签提示。
- 提示使用适当 status / alert 语义，不抢焦点、不遮挡 Dock，不因普通开窗反复打断读屏；读屏实机检查结果单独记录。

## 终端、偏好与降级

- 中文输入法合成时 Enter 不提交命令，合成期间 Ctrl / ⌘ K 不误触发搜索。Tab 补全命令、应用和壁纸参数；Shift+Tab 能离开输入；↑/↓ 浏览历史并恢复未提交草稿。
- `help` 与实际命令一致，逐项试用 `whoami / ls / pwd / cat README.md / open / neofetch / theme / date / echo / clear`，未知命令、错误参数和超长输入给出可读反馈；HTML 文本只显示为文本，`clear` 保留命令历史。
- 将手机横屏键盘可视高度降至约 200px 及更低，核对窗口滚动区和 Dock 互不覆盖；输入和关闭控件可滚动到达，极短高度和安全区下仍能滚动到导航。在阅读旧输出时执行命令，再按空输入 Tab，叠加新输出、补全与错误提示，确认输入仍可滚动到达；未聚焦输入时不抢阅读位置，已聚焦的提示符在键盘变化时允许滚入可见区域；紧凑呈现不显示无效最大化 / 缩放入口。键盘开关、焦点滚入与搜索取消不重建会话或普通几何。
- 超过 100 条历史、200 条输出后旧记录按限额移除；原在底部时跟随输出，阅读旧记录时位置不跳动且提示新增。真机软键盘开关只调整可见区，不重建会话；输入与 Dock 均可达。
- 设置与终端修改壁纸相互同步；动效关闭与系统减弱动态效果正确叠加。刷新只恢复偏好，终端历史、草稿和窗口布局不跨刷新保存。
- 限制浏览器存储权限、构造损坏 JSON / 未知值 / 不支持版本，确认桌面仍可使用；写入失败后当前壁纸仍改变，设置明确提示仅本次访问有效，不声称已保存。
- 用本地受控的单应用渲染故障检查错误边界：可重试或回到桌面，其他应用仍可使用；不把故障注入到生产配置。
- 禁用 JavaScript 后重新加载，仍能看到品牌和简介；公开导航只来自已配置有效地址，无假链接或私人原型身份。恢复 JavaScript 后桌面正常。
- 正式地址配置后检查 title、description、语言、favicon、canonical / Open Graph 与实际域名一致，已配置博客与联系方式实际可访问。未配置的可选资料保持隐藏。

线上 Actions、部署并发、DNS、真实访问和回退的验收另见 [发布说明](deployment.md)，不得用本清单中的本地操作代替。
