# HonestOS macOS 风格细化

状态：2026-10-23 的视觉细化已确认；后续架构整理已将博客改为手动精选（ADR-0003），品牌素材统一由 public 提供。冲突处以以下已确认行为为准。

## 设计基线

参考用户本轮的两张原型截图、Apple macOS Tahoe 与 Materials 指南。旧交接包本地已不存在，不声称读取了该原型源码。

- 雾白 #F5F5F7、石墨 #242426、次级灰 #86868B、系统蓝 #007AFF、暮紫 #77708E、玻璃高光 #FFFFFF。
- 系统 UI 字体；终端 SF Mono / Menlo 等宽字体。正文 14px，窗口标题 13px，内容标题 20–24px；手机输入保留 16px 以避免自动放大。
- 左对齐的紧凑内容；玻璃集中于 Dock、标题栏、设置侧栏，内容表面维持可读性。
- 动效回答操作：窗口开合、最小化、Dock 反馈和切换；使用 GSAP，站内与系统减弱动态效果均优先生效。
- 移除顶部菜单栏及导航、背景大字、装饰性标语；保留 Dock、桌面快捷入口与窗口。

```text
┌───────────────────────────────────────────┐
│                                           │
│   ┌──── 关于我 ───────┐        项目 / 博客  │
│   │ 头像  honestman   │                    │
│   │ 紧凑介绍与操作     │  ┌── bash ────────┐│
│   └──────────────────┘  │ 输出             ││
│                         │ user@host:~$ _  ││
│                         └────────────────┘│
│             [ HM 项目 博客 终端 设置 搜索 ]│
└───────────────────────────────────────────┘
```

审视：不套用大字号 hero 或等高营销卡片；将头像与真实内容作为个人身份，山峦与紧凑终端保留 HonestOS 特征。原计划的大幅背景品牌、常显辅助文案已移除，减少重复视觉噪声。

## 已确认行为

1. 窗口整组三色控制默认隐藏，进入标题栏或键盘焦点进入窗口后显示；触屏始终显示。标题栏收紧，保留可达操作。
2. Bash 风格提示符 `honestman@HonestOS:~$`；记录与当前输入排列在同一滚动区域，保留现有虚拟站点命令、IME、历史、补全、阅读位置与会话语义。
3. 博客文章由作者在 `siteConfig.blog.posts` 手动精选，按配置顺序展示并跳转独立博客；移除 RSS 同步、解析器与快照。配置方式见 [开发说明](../development.md#手动精选文章)，决策见 [ADR-0003](../adr/0003-manually-curated-blog-posts.md)。
4. 设置包含浅色/深色/跟随系统、内置图片、本地上传壁纸、背景明暗、玻璃透明度、Dock 大小和自动隐藏、动效、恢复默认及整理桌面。
5. 上传壁纸仅保存在当前浏览器，不上传服务器。偏好升级兼容旧版；保存失败提供本次访问降级与明确反馈。
6. 使用用户提供的 HM 明暗标志和头像，唯一来源为 `public/` 中的三个文件，应用直接引用；不再维护 `src/assets/brand/` 副本。用户未提交的内容配置独立保留。
