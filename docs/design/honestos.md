# HonestOS 当前设计

本文是现行产品行为的统一入口。历史方案保存在 [历史归档](../history/)，决策理由见 [ADR](../adr/)，开发和发布操作分别见 [开发说明](../development.md) 与 [发布说明](../deployment.md)。历史资料不覆盖本文。领域术语见 [GLOSSARY](../../GLOSSARY.md)。

## 产品范围

HonestOS 是 honestman 的桌面式个人主站，用于个人介绍、项目展示与独立博客导航。包含关于我、我的项目、随便写写、终端、桌面设置五个应用，每个应用同时最多一个应用会话。

主站配置独立博客入口和 RSS 地址，在客户端读取文章标题、摘要、链接与可选日期，按订阅源顺序展示；正文与发布系统由独立博客负责。未配置博客入口时显示筹备中，不生成假链接。此边界由 ADR-0001 和 ADR-0004 确认。

当前范围不包含账户、CMS、服务端数据库、真实 Shell、在线代码执行、AI 聊天、窗口深链或跨刷新恢复应用会话。

## 视觉与入口

- 保留暮色山峦、紧凑内容窗口、深色终端、桌面快捷入口与 Dock；顶部状态栏提供统一信息与控制入口，不显示背景大字或装饰性标语。
- 系统字体栈，正文约 14px，内容标题 20–24px；手机输入字号 16px。玻璃效果集中于顶部状态栏、Dock、窗口标题栏和浮层，设置侧栏保持半透明层次，正文使用稳定底色，终端保持深色。
- 使用 `public/` 中的头像、HM 明暗标志与 favicon，维护单一素材来源。标签页图标复用明暗 HM 标志，跟随站点的实际外观；应用启动前及无 JavaScript 时跟随系统明暗。当前公共文案由 `src/config/profile.ts`、`src/config/projects.ts`、`src/config/blog.ts` 与 `src/config/system.ts` 分域定义，并由 `src/config/content.ts` 聚合导出。
- 首屏在未开启减弱动效时展示短时入场头像加载进度条（`BootScreen`），呈现头像光环、署名与阶段进度，支持指针或按键立即跳过，且不阻塞主桌面与辅助技术树。
- 精细指针设备提供高对比度系统级矢量指针与轻微液态玻璃跟随光环（`CustomCursor`）；触屏与减弱动效环境自动停用跟随层。
- Dock 提供五个应用和搜索；桌面快捷入口指向项目、博客和关于我（由 `system.shortcuts` 配置驱动）。点击活动应用只聚焦，不切换为关闭或最小化。
- 三色窗口控制在标题栏悬停或窗口获得键盘焦点时显示，触屏常显。桌面标题栏紧凑，触摸控件目标约 44×44px。
- GSAP 提供短促平滑、轻微回弹的窗口、Dock 与浮层反馈；空闲不循环。最小化朝 Dock 入口收拢，恢复沿相同方向展开；无法测量入口时轻微缩放淡入淡出。最大化插值位置和尺寸，不缩放正文。触屏不使用 Dock 悬停放大。
- 关闭、最小化和焦点立即更新，不等待动画。快速反向操作、关闭动效、改变视口等中断会取消过时反馈，不能覆盖新状态或改变会话语义。系统减弱动态效果优先于站内开关。

默认窗口尺寸与最小尺寸由 `src/config/registry.ts` 维护，实际几何约束到可用区域。初访桌面打开关于我和终端，终端位于前景但不自动聚焦输入；关于我的主操作应保持可见。初访单窗口模式只打开关于我。

## 顶部状态栏与浮层

桌面左侧为 HM 菜单与活动应用名，右侧为搜索、控制中心和本地日期时间；没有活动应用时显示 HonestOS。HM 菜单的“关于本站”打开关于我，“整理桌面”复用现有布局操作；状态栏搜索与 Dock、快捷键使用同一搜索面板。状态栏及其浮层属于桌面界面，不创建应用会话。

手机保留 HM 菜单、时间和控制中心，隐藏活动应用名、顶部搜索与日期文字；Dock 搜索仍可用。窗口可用区域、最大化、默认构图和桌面快捷入口均避开状态栏，单窗口与软键盘场景继续保留应用会话。

控制中心提供浅色/深色/跟随系统、背景亮度、玻璃不透明度、动效开关和“打开桌面设置”。它与设置共享偏好、保存状态和降级反馈，双向立即同步，刷新后按现有偏好规则恢复；不保存浮层开关。

日期时间使用访客设备本地时间，精确到分钟，并在页面重新可见或获得焦点时校准。只读日历按周一至周日排列，支持跨年切换月份和回到今天，今日标记随本地日期更新；重新打开时从当前月份开始。不保存浏览月份，也不请求远程日历，不提供日程、提醒或账户。

HM 菜单、控制中心和日历同一时刻只打开一个。触发按钮有可访问名称与展开状态，打开时焦点进入浮层；再次触发或 Escape 关闭并恢复触发按钮焦点，点击或聚焦外部则关闭并保留外部目标。HM 菜单支持方向键与 Home/End。浮层非模态，Tab 可离开；离开后隐藏控件退出交互范围。打开应用时焦点交给应用，搜索继续遵守其模态隔离规则。

## 玻璃材质与兼容

玻璃以磨砂、高光与半透明层次为基础，支持时在独立装饰层增加轻微边缘折射；正文与控件不参与变形。无折射时保留磨砂与高光，无背景滤镜时使用实色回退；系统减少透明度时关闭磨砂和边缘折射，优先可读性。

参考 childrentime/liquid-glass 的距离场与位移贴图思路，适配为共享静态贴图，不引入拖动透镜或闲置持续计算。CSS 能力判断不证明实际渲染正确，也不承诺各浏览器像素一致。实现取舍见 [玻璃与动效实现说明](glass-material.md)；人工验收记录见 [交付状态](../delivery.md)。

## 应用会话与窗口

应用会话、窗口可见性和活动应用是不同事实。同一时刻最多一个活动应用，也可以没有。

| 操作 | 会话与呈现 |
| --- | --- |
| 打开已关闭应用 | 创建新会话，显示并置前 |
| 打开已运行应用 | 继续原会话，聚焦；若最小化则先恢复 |
| 最小化 | 隐藏窗口，保留会话与 Dock 运行指示 |
| 关闭 | 结束会话并清理临时状态，移除运行指示 |
| 单窗口切换前景 | 后台会话继续存在 |
| 刷新 | 重建首访会话和布局，仅恢复桌面偏好 |

终端记录、草稿、命令历史和应用内阅读位置属于会话。关闭后立即重开也必须得到新的会话身份。隐藏后台与最小化应用退出键盘和辅助技术交互范围；桌面仍可见的非活动窗口保持交互能力。

关闭或最小化活动应用后，切换到最近使用的其他 open 应用；没有候选则回到桌面。不会自动恢复 minimized 应用或重开 closed 应用。焦点交给可见后继窗口或 Dock，关闭非活动窗口不改变活动应用。

整理桌面保留所有运行会话和偏好：桌面恢复关于我、终端的默认构图，其他运行应用最小化；单窗口将关于我置前。已关闭的默认应用可重新建立会话，其他已关闭应用保持关闭。整理操作不主动聚焦终端输入。

## 几何与响应式

- 标题栏空白处拖动，可见右下角手柄缩放；指针结束、取消或捕获释放都停止操作。桌面状态与拖动预览共用几何约束。
- 绿色按钮和标题栏双击切换可用区域内最大化，保留普通几何用于恢复。最大化不调用浏览器全屏。
- 宽度小于 1024px，或空间无法容纳窗口最小尺寸时，采用单窗口模式。单窗口不写回桌面普通几何，隐藏最小化、最大化和缩放操作。
- 跨模式、旋转和视口缩小不重建会话；回到桌面后恢复仍运行应用的几何并约束到当前可用区域。
- 软键盘与极短可视高度只调整呈现。紧凑模式使用可滚动应用区和 Dock 的网格，必要时外层也可滚动；只显露已聚焦的终端输入，不主动聚焦或重置会话。

## 应用内容

关于我展示作者介绍、兴趣、状态与已确认公开的联系方式；主操作打开项目，次操作打开终端并明确聚焦输入。

我的项目使用紧凑的单列作品列表：48px 缩略图、名称、状态、可选年份与“本站”标识，简介选填；没有简介或只有空白时不保留段落。列表不展示分类、技术栈或功能亮点，不提供站内详情。项目内容区宽度大于 600px 时操作位于右侧，否则放在文字下方并允许换行；名称与整行不可点击。在线地址、源码地址和项目介绍文章各自独立，按此顺序在新标签打开，仅显示有效入口。详细介绍用 Markdown 在独立博客发布，主站只维护可选文章链接，不保存或渲染正文。项目状态为 live / building / idea / archived，“本站”是独立身份；本站不展示自链，构想项目无演示入口，源码和文章不受这两项限制。live 必须配置真实在线地址。最小化、后台及窗口尺寸变化保留列表滚动位置，关闭重开回到顶部。空列表和图片失败有可用降级。

随便写写展示独立博客入口和订阅源文章；缺失入口不影响其他内容。首次打开应用后，浏览器直接请求配置的 RSS 地址，展示加载、空列表或失败重试状态；请求 15 秒超时，关闭会话时取消请求，最小化和后台保留已加载内容。订阅源需允许跨域读取，失败时保留博客入口。主站不保存文章正文，不在构建时抓取文章。

项目、博客、设置按首次打开延迟加载；关于我和终端首屏可用。加载中有状态提示，失败在窗口内重试；关闭会话后加载完成不重新开窗。

## 终端

终端是预定义命令入口，以 `honestman@HonestOS:~$` 提示符呈现。记录与当前输入位于同一滚动区域。解析和执行返回纯文本与操作意图，界面处理开窗、偏好与滚动。

| 命令 | 行为 |
| --- | --- |
| help | 从实际定义生成帮助与参数提示 |
| whoami | 公开个人介绍 |
| ls / pwd | 应用清单、虚拟 README.md / 虚拟路径 |
| cat README.md | 虚拟说明文本，其他路径给出用法 |
| open | 按注册表打开应用，保留已存在会话 |
| neofetch | 品牌、实际站点版本与虚拟 Shell 标识，不冒充设备检测 |
| theme | 从壁纸注册表选择内置壁纸 |
| date / echo | 本地日期时间 / 原样纯文本 |
| clear | 清空输出，保留本会话命令历史 |

空提交无副作用，首个命令词忽略大小写；未知命令只产生普通输出。IME 合成中的 Enter 不提交。上下键浏览历史并恢复草稿；Tab 补全，Shift+Tab 可离开输入。

输入最多 2,000 字符，历史最多 100 条，输出最多 200 条记录，超限丢弃最旧内容。仅在原本位于底部时跟随输出；阅读历史时保持位置并提示新输出。不持久化终端输入或历史。

## 搜索与焦点

Ctrl/Cmd+K 切换搜索，IME 合成期间不触发。按注册表匹配名称、ID、别名与关键词，去除首尾空格并忽略英文大小写；空查询展示所有应用，无结果显示空态。

方向键选择，Enter 打开，Escape 或遮罩取消。搜索显示时背景 inert，焦点限制在面板中；取消恢复可见触发目标，打开应用则交给目标窗口。普通窗口不是模态对话框，不限制 Tab 离开。

## 桌面偏好

设置支持浅色/深色/跟随系统、五种内置壁纸、自选图、背景亮度、玻璃不透明度、Dock 大小与自动隐藏、动效、恢复默认和整理桌面。

偏好保存在 `honestos.preferences.v1`，当前值为 schema 2，兼容旧 schema 1 的壁纸与动效。存储不可用、数据损坏、未知值或不支持版本均安全降级。恢复默认同时删除自选图，不结束会话。

自选图仅在当前浏览器 IndexedDB 保存，不上传服务器；支持 JPG/PNG/WebP/AVIF，最多 10 MB，使用前验证可解码。上传、恢复和重置有顺序保护，object URL 替换或卸载时释放。保存失败保留本次访问选择并给出反馈。

偏好值、稳定操作、保存状态和最终动效状态分别订阅，避免保存反馈或外观调整使全部应用正文重渲染。

## 内容、降级与交付

公开内容由配置统一提供，构建校验重复身份、非法链接、RSS 地址与 live 项目地址。网页链接只接受合法绝对 http/https，邮箱单独处理；未确认的地址保持未配置。配置校验不证明网站所有权或可访问性。

初始 HTML 从同一配置生成标题、描述、无 JavaScript 简介与导航；正式 URL 配置后生成 canonical 与分享元信息。应用错误局部恢复，不使整个桌面失效。

React/TypeScript/Vite/CSS 实现静态前端，useReducer + Context 管理状态。开发和预览使用普通 Vite；Wrangler 保留 Workers Static Assets 部署能力。PR 自动检查，main 检查通过后发布同一构建；详见发布说明。

自动验证覆盖状态、交互、内容、持久化和构建，视觉、辅助技术与真机体验人工验收。首屏目标为初始 JS gzip 约 200 KB、静态首屏资产约 1 MB；历史测量不代表当前产物。验收场景集中维护于 [人工验收清单](../manual-acceptance.md)，实际结果见 [交付状态](../delivery.md)。
