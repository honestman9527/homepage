日期：2026-10-23。设计依据与确认范围见 [设计记录](design/macos-refinement.md)。本轮保留开发分支 `feat/macos-desktop`，不合入 main、不推送或部署。

## 已实现

- 移除顶部菜单栏、重复应用导航、背景大字及装饰性文案；重新计算桌面与手机的窗口可用区域，初始两窗按视口高度安排。
- 36px 桌面标题栏、居中小标题、紧凑三色控制；悬停/焦点显示，触屏常显。Dock 的尺寸、提示、运行指示与玻璃表面统一；正文 14px，内容标题 20–24px。
- 接入用户头像与 HM 明暗图形，favicon 跟随系统明暗。品牌构建副本放在 `src/assets/brand/`，原始 public 文件不改动或提交。
- 终端为 Bash 风格提示符、记录和输入同区滚动；取消固定底部输入条与常显执行按钮。保留 IME、历史、草稿、补全、会话与阅读恢复；新输出反馈浮在可见位置。
- 设置包含外观、五种内置壁纸（含两张照片）、本地上传、自选图恢复、背景亮度、玻璃不透明度、Dock 大小/自动隐藏、动效、恢复默认和整理桌面。
- 偏好 schema 2 兼容 schema 1；图片在 IndexedDB 保存，校验类型/大小/解码，失败保留本次访问选择。上传、读取与重置有顺序保护，object URL 在替换和卸载时释放。
- GSAP 窗口进入、退出、最小化与 Dock 邻近缩放；复用 quickTo 动画，作用域清理；动画期间切换应用不抢焦点，关闭动效会完成正在进行的操作。系统减弱动态效果优先。
- RSS/Atom 构建期元数据模块、明确的快照同步命令、失败回退与独立文章外链。解析器留在构建侧，运行时无订阅源请求。

## 已执行验证

- 主工作区严格 TypeScript 检查、生产构建、Git diff 空白检查通过。
- 相关界面、偏好、图片、应用会话、窗口、搜索、配置与 RSS 定向集合：15 个文件 59 项通过；其后配置/博客 9 项、桌面/App 21 项、最终 App 动效/焦点 13 项的定向复核通过。这里记录实际运行，不将重叠检查相加为独立测试总数。
- 图片存储使用 fake-indexeddb 验证真实事务的保存、替换与删除；上传与重置并发、恢复旧图与新上传并发、解码失败、保存失败和 URL 释放均有功能检查。
- RSS 单元检查覆盖 RSS/Atom、相对链接、去重排序、纯文本摘要、安全外链、无效 XML、读取失败、回退与不同来源隔离。`blog:sync` 对无效示例来源返回失败并保留原快照；这不代表真实博客同步成功。
- 导出暂存区的独立目录，排除用户原有四个未提交路径。使用独立 node_modules 执行 frozen-lockfile 安装、类型检查、五个关键文件的 29 项测试和构建，全部通过，确认提交不依赖用户未提交资料。
- 初次独立目录尝试复用 node_modules 软链接触发 pnpm 校验警告；随后移除链接，独立安装并完整重跑上述检查，最终验证无此问题。

## 文件体积

主工作区最终构建，Node 24 gzipSync 默认压缩方法，单位为字节：

| 内容 | 原始体积 | gzip |
| --- | ---: | ---: |
| JavaScript | 347,571 | 114,568 |
| CSS | 27,797 | 6,918 |
| 头像 | 315,258 | 315,376 |
| HTML | 1,911 | 1,001 |
| favicon | 579 | 389 |

默认页面引用的上述文件原始体积合计 **693,116 B**；JS gzip 低于约 200 KB 目标。照片按选择使用，默认山峦不请求照片；这些是文件测量，不是浏览器网络或 CWV 测量。

包含可选照片的独立提交快照产物共 **1,176,291 B**；主工作区因为还复制了用户未跟踪的 public 原始头像与标志，共 **1,493,291 B**。如果将约 1 MB 目标解释为全部静态发布目录，本轮超出；默认引用文件集合仍低于 1 MB。未为压缩预算改动用户原始图片。
