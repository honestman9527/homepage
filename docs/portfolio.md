# 作品案例

项目基本信息统一保存在 `src/data/projects.yaml`，案例正文位于 `src/content/cases/`，支持 Markdown 和 MDX。每个项目最多关联一个案例，文件名不决定公开地址。普通正文优先 Markdown，需要组件时使用 MDX。

## 写作与发布

仓库提供关联 Navigation 项目的 `navigation.md` 草稿模板，提纲需要作者补充真实内容。填完后显式设置 `draft: false` 才发布：

```yaml
---
projectId: CF-Workers-Navigation
slug: navigation
draft: true
toc: true
---
```

| 字段 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `projectId` | 是 | — | 项目 YAML 中已有的 `id`，区分大小写 |
| `slug` | 是 | — | 稳定 URL 标识，只接受小写字母、数字和单连字符分隔 |
| `draft` | 否 | `true` | 草稿不生成详情页或卡片案例入口 |
| `toc` | 否 | `true` | 显示二级、三级标题目录；关闭后仍显示阅读进度 |

schema 严格拒绝未知字段。标题、摘要、年份、标签、封面与外链均取自关联项目，不在案例 frontmatter 重复维护。`page` 为项目分页保留值，不能作为案例 slug。包括草稿在内，重复 slug、重复项目关联或不存在的项目都会让构建失败。

为另一个项目写案例时新建文件，并使用其项目 ID 与独立 slug；为同一个项目更新案例时编辑原文件。重命名文件不会改变 URL，修改 slug 会改变 URL。项目 ID 改名时同步修改案例关联。

## 展示边界

发布后生成 `/projects/{slug}`，项目卡片标题在当前标签页进入案例；未发布案例时，标题仍在新标签页打开项目外链。查看项目与在线演示始终保留为外链。

案例页复用公共布局、项目封面、正文、目录和阅读进度，提供返回项目列表入口。案例使用项目的封面回退规则，不提供博客评论、博客标签链接或相邻文章，也不进入博客搜索、标签和文章列表。

修改后串行运行 `pnpm test`、`pnpm check`、`pnpm build`。发布案例还需人工检查桌面／手机、主题、目录与进度、站内导航、前进后退和音乐连续播放。
