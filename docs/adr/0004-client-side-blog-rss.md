# 客户端直接读取 RSS 文章

取代 [ADR-0003](0003-manually-curated-blog-posts.md)。按维护者要求，主站不再手动维护精选文章，在博客应用打开后由浏览器直接请求 `blog.rssUrl`。博客入口 `blog.url` 独立配置，文章正文继续由独立博客承载，延续 ADR-0001 的内容边界。

这样文章更新无需修改主站或重新构建，也无需服务端代理或构建快照；代价是文章列表依赖访客网络与订阅源的可用性、RSS 格式及 CORS 配置。加载失败或超时提供重试并保留博客入口，关闭会话取消未完成请求。远程 HTML 不插入界面，只展示标题、纯文本摘要、日期与经过校验的文章链接。
