# Triage Labels

技能中的五个标准角色映射到以下 GitHub 标签。

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可以交由代理实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

技能提及某个分诊角色时，使用对应的仓库标签。
后续调整标签名称时，更新“仓库标签”列。
